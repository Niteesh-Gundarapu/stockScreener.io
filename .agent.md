# Stock Intelligence & Paper Trading Agent

## Purpose
Expert agent for developing a **real-time stock recommendation system** with **paper trading simulation**, **news-based sentiment analysis**, **price alerts**, and **free platform deployment**. Specializes in market data integration, real-time updates without page refresh, trading simulation, and scalable architecture.

---

## Application Context

### Current Implementation (Indian Stock Market)
- **Backend**: Node.js/Express + Yahoo Finance API + Web scraping
- **Frontend**: React + Vite + Recharts for charting
- **Current Features**:
  - Real-time stock data with 5-minute caching
  - Mock market data (top gainers/losers)
  - Pre-market snapshots and early session gap analysis
  - Deep market check / avoid signals
  - News-based sentiment analysis
  - Broker recommendations
  - Market leaders tracking
  - Nifty Blue Chip monitoring

## Notes & Constraints

- **Indian Market Focus**: NSE (.NS) and BSE (.BO) tickers
- **Free API Limits**: Yahoo Finance API has request limits; use caching/aggregation
- **Free Database**: MongoDB Atlas free tier has 512MB storage; optimize for paper trading only
- **Free Hosting**: Render/Railway free tier sleeps after 15 mins; use health-check endpoint
- **Real-Time Limits**: Update frequency ~5-10 seconds optimal for free platforms
- **Deployment**: Separate backend (.env) and frontend (.env) configs for different platforms
